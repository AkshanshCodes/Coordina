# Getting Help

| You want to | Go to |
| --- | --- |
| Ask a question or discuss an idea | [Discussions](https://github.com/Neptune2k21/Coordina/discussions) |
| Report a bug | [New bug report](https://github.com/Neptune2k21/Coordina/issues/new?template=bug_report.yml) |
| Propose a feature | [New feature request](https://github.com/Neptune2k21/Coordina/issues/new?template=feature_request.yml) |
| Report a vulnerability | [Private security advisory](https://github.com/Neptune2k21/Coordina/security/advisories/new), see [SECURITY.md](SECURITY.md) |
| Contribute code or docs | [CONTRIBUTING.md](CONTRIBUTING.md) |

Coordina is maintained on a best-effort basis. Questions asked in Discussions
help the next person too, so prefer them over private messages.
