The API exposes its OpenAPI schema and an interactive Scalar tester at runtime.
Mintlify owns the long-form docs, while the API continues to own the generated
contract.

Board workflow semantics (list `taskStatus`, how completion follows it, and the
`409` cases) are described on the [Boards](/boards) page.

## Register example

```bash
curl -X POST http://localhost:5050/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Maya Chen",
    "email": "maya@coordina.test",
    "password": "Password123!"
  }'
```

## Production docs

When the API has a public base URL, add that URL to the OpenAPI `servers`
metadata or publish a generated `openapi.json` inside this docs directory. Then
Mintlify can render endpoint pages from the same contract.
